# wenjagames.github.io

Website for Wenja Games, served by GitHub Pages at
<https://wenjagames.github.io>.

| File | URL | Used by |
|---|---|---|
| `index.html` | https://wenjagames.github.io/ | Play listing "Website" field |
| `privacy.html` | https://wenjagames.github.io/privacy.html | Play Console privacy policy, AdMob |
| `app-ads.txt` | https://wenjagames.github.io/app-ads.txt | AdMob seller verification (added after the AdMob app exists) |
| `icon.png` | — | page icon (Block Puzzle) |
| `.nojekyll` | — | serve files as they are, without Jekyll |

Contains no secrets: the AdMob publisher ID in `app-ads.txt` is public
by design.
